🚀 Cómo Usar Este Proyecto

👤 Para Usuarios Nuevos

  1. Abra LEEME.html
  2. Lea las instrucciones
  3. Haga clic en "Aplicación"
  4. Use admin/admin123

👨‍💻 Para Desarrolladores

  1. Revise README.md
  2. Examine assets/js/
  3. Vea la estructura
  4. Personalize según sea necesario

🔧 Para Administradores

  1. Use admin-tools.html
  2. Haga backup regular
  3. Cargue datos
  4. Exporte información
