➕ Crear Producto

Pasos:

  1. Ir a: Gestión de Productos
  2. Hacer clic: Agregar Producto
  3. Completar: Nombre, Categoría, Precio
  4. Ingresar: Cantidad, Stock Min/Max
  5. Guardar

Solo Administrador

✏️ Editar Producto

Pasos:

  1. Ir a: Gestión de Productos
  2. Localizar: Producto a editar
  3. Hacer clic: Botón Editar ✏️
  4. Modificar: Los datos necesarios
  5. Guardar

No modifica stock existente

🗑️ Eliminar Producto

Pasos:

  1. Ir a: Gestión de Productos
  2. Localizar: Producto a eliminar
  3. Hacer clic: Botón Eliminar 🗑️
  4. Confirmar: La acción

⚠️ Acción irreversible

🏷️ Categorías

Crear:

  1. Ir a: Categorías
  2. Ingrese: Nombre de categoría
  3. Hacer clic: Agregar

Eliminar:

Solo sin productos asociados

⬆️ Registrar Entrada

Pasos:

  1. Ir a: Registrar Entrada
  2. Seleccionar: Producto
  3. Ingresar: Cantidad
  4. Opcional: Observaciones
  5. Guardar

Para empleados y admin

⬇️ Registrar Salida

Pasos:

  1. Ir a: Registrar Salida
  2. Seleccionar: Producto
  3. Ingresar: Cantidad
  4. Elegir: Tipo de salida
  5. Guardar

Tipos: Venta, Pérdida, Daño, Devolución
