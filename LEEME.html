⚠️ Información Importante

  • ✓ La aplicación funciona sin servidor - todo está en localStorage
  • ✓ Los datos persisten al cerrar o actualizar el navegador
  • ✓ No requiere conexión a internet (excepto para cargar Tailwind CSS)
  • ✓ Compatible con Chrome, Firefox, Edge, Safari
  • 📁 Los datos se guardan en localStorage del navegador
  • 🔒 Hacer backup regularmente usando admin-tools.html
  • ⚠️ Limpiar datos del navegador eliminará todo permanentemente

📋 Próximos Pasos

  1. Abra index.html en su navegador
  2. Inicie sesión con admin / admin123
  3. Cree categorías en "Gestión de Categorías"
  4. Agregue productos en "Gestión de Productos"
  5. Registre movimientos o cambie a empleado para hacerlo
  6. Explore las estadísticas y reportes
