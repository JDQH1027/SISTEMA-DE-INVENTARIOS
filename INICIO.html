📖 Guía de Uso

Para Administrador

1. Crear Productos

Vaya a "Gestión de Productos" → "Agregar Producto" → Complete los datos (nombre, categoría, precio, cantidad, stock mín/máx)

2. Gestionar Categorías

Vaya a "Categorías" → Agregue nuevas categorías o elimine las existentes

3. Ver Estadísticas

Vaya a "Estadísticas" para ver: valor total del inventario, productos con bajo stock, productos más movidos, alertas del sistema

4. Gestionar Usuarios

Vaya a "Usuarios" → Cree nuevos usuarios, active/desactive o elimine según sea necesario

Para Empleado

1. Registrar Entrada

Vaya a "Registrar Entrada" → Seleccione el producto → Ingrese la cantidad → Agregue observaciones → Guardar

2. Registrar Salida

Vaya a "Registrar Salida" → Seleccione tipo de salida (venta/pérdida/daño) → Ingrese cantidad → Guardar

3. Ver Inventario

Vaya a "Inventario" para ver todos los productos y sus cantidades disponibles

🔧 Información Técnica

  • Tecnologías: HTML5, CSS (Tailwind), JavaScript Vanilla, localStorage
  • Almacenamiento: Todos los datos se guardan en localStorage del navegador
  • Compatibilidad: Chrome, Firefox, Edge, Safari (versiones modernas)
  • No requiere: Servidor, base de datos, conexión a internet

⚠️ Notas Importantes

  • ✓ Los datos se guardan automáticamente y persisten al cerrar el navegador
  • ✓ Limpiar datos de navegador eliminará toda la información
  • ✓ No requiere conexión a internet para funcionar
  • ✓ Los datos son locales y privados en su navegador
  • ✓ Se recomienda usar en navegadores modernos actualizados
